## 可复现性

本次实际环境：macOS 27.0 / Apple Silicon arm64，Node.js 24.16.0，npm 11.13.0。

从拟发布的 Git 暂存内容导出全新目录，不复用原项目的 node_modules、SRS、编译产物或本地账本，依次执行：

```sh
npm ci --no-audit
npm run bootstrap
npm test
npm run test:model
npm run build
```

以上全部成功。bootstrap 下载固定版本的官方 Nargo、生成真实验证器并编译合约；新生成的 Verifier.sol 与仓库版本哈希一致。锁文件未被安装过程改写。

另完成 Linux x64 的 npm 依赖解析 dry-run；它不等同于 Linux 系统的实际运行测试。
